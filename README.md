`base_wide.csv` : Base em formate wide, com a chave única `id_family_datalake` como identificadora da família, `FavelaID` indica a favela, e cada pergunta em colunas `<pergunta>_FIRST` e `<pergunta>_LAST` indicando a primeira e última resposta da família para a pergunta em questão.

`base_log.csv` : Qual o tempo da resposta de cada família para cada pergunta incluída na `base_wide`
